# 🚫 Dépan'PC Anti-Pub

> Bloque les **publicités et les traceurs** sur **tout votre PC** (tous les navigateurs et applications), en un clic. Gratuit.

![Version](https://img.shields.io/badge/version-1.0-15392b)
![Plateforme](https://img.shields.io/badge/Windows-10%20%7C%2011-0d6efd)
![Licence](https://img.shields.io/badge/licence-gratuit%20(tous%20droits%20r%C3%A9serv%C3%A9s)-c77700)

Outil **gratuit** développé par **[Dépan'PC](https://depan-pc.fr)**.
Il active un DNS filtrant (AdGuard) qui bloque la majorité des publicités et des traceurs, partout sur votre ordinateur — pas seulement dans un navigateur. Aucune installation : un simple double-clic suffit, et tout est **réversible**.

---

## 📥 Télécharger

1. Rendez-vous dans la section **[Releases](../../releases)** (à droite de cette page).
2. Téléchargez le fichier `DepanPC-AntiPub.zip`.
3. Décompressez-le (clic droit sur le `.zip` → **Extraire tout**).

> ✅ Téléchargez uniquement depuis cette page GitHub ou depuis **[depan-pc.fr](https://depan-pc.fr)**. Ne faites pas confiance à une copie trouvée ailleurs.

---

## 🚀 Utilisation

1. Ouvrez le dossier décompressé.
2. Double-cliquez sur **`Lancer_BloquerPubs.bat`**.
3. Windows demande l'autorisation administrateur → cliquez sur **Oui**.
4. Dans la fenêtre, cliquez sur **« Activer le blocage des publicités »**.

Pour revenir en arrière : cliquez sur **« Désactiver / revenir en arrière »** (vos DNS repassent en automatique).

---

## ⚠️ « Windows a protégé votre ordinateur »

C'est **normal et sans danger**. Comme l'outil est gratuit et non signé par un certificat payant, Windows affiche un message de précaution pour tout fichier téléchargé sur Internet.

Pour continuer :
- Cliquez sur **« Informations complémentaires »**
- Puis sur **« Exécuter quand même »**

**Si votre antivirus le bloque** : il s'agit d'un faux positif (les scripts qui touchent au réseau sont parfois signalés par excès de prudence). Vous pouvez l'autoriser, ou le retélécharger depuis la source officielle. Le code étant **ouvert**, vous pouvez l'inspecter avec le Bloc-notes.

## ❓ Questions fréquentes

**Ça bloque vraiment toutes les pubs ?**
Une grande partie des publicités et des traceurs, oui — mais pas 100 %. Certaines publicités intégrées (comme sur YouTube) passent au travers, car elles viennent du même serveur que la vidéo.

**Ça ralentit Internet ?**
Non. Au contraire, en supprimant le chargement de nombreuses pubs, la navigation est souvent plus légère.

**C'est réversible ?**
Oui, totalement. Le bouton « Désactiver » remet vos réglages d'origine (DNS automatique de votre box).
